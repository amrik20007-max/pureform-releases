Витамины, минералы, омега-3 и спортивное питание в одном приложении: поиск, избранное, кэшбэк до 10 % и подарочные сертификаты.

Главное окно приложения: поиск, категории и сортировка.

Как установить

  1. Скачайте установщикНажмите «Скачать для Windows». Файл PureForm-Setup.exe появится в папке «Загрузки».
  2. Запустите файлДважды щёлкните по нему. Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
  3. Дождитесь установкиПервая настройка может занять до минуты. После неё PureForm появится в меню «Пуск».
  4. Войдите или создайте аккаунтНовые версии приложение предложит установить само.
Предупреждение Windows появляется потому, что установщик пока не имеет платной цифровой подписи. Скачивайте файл только с этой страницы.
